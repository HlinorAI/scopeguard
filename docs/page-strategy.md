# ScopeGuard — first product surface

## Product read

ScopeGuard is a local-first evidence review tool for small agencies. It compares an agreed SOW with the requests appearing in communication and makes potential margin leakage visible before work begins.

## First user journey

1. User opens a project.
2. User adds the SOW and a communication export.
3. ScopeGuard compares the two sources.
4. User sees potential scope drift with evidence, scope basis, confidence and estimated hours.
5. User reviews a finding and decides whether to clarify, absorb or issue a change request.

## First screen requirements

- project context and saved-local status;
- clear analysis state;
- amount of scope coverage and hours at risk;
- evidence list with filters for all, high risk and unreviewed;
- source list with add/drop affordance;
- local-first privacy reassurance;
- no legal verdict language.

## Out of scope for this surface

Integrations, billing, authentication, live sync and automated legal conclusions are intentionally deferred.
